 A5. LA FATIGA MANDA SOBRE EL INTERRUPTOR
-------------------------------------------------------------------------------

  [ ] A5.1  Con el ojo ENCENDIDO: `/dojutsudojutsu strain 100`.
            ESPERADO (en 1 tick): dos mensajes en rojo ("Your eyes are too
            strained..." + el porcentaje) y el ojo se APAGA solo.
  [ ] A5.2  *** EL ARREGLO IMPORTANTE ***  `/dojutsudojutsu get`
            ESPERADO: `activeEye=sharingan enabled=false`
            NO ESPERADO: `activeEye=(ninguno)`
            ANTES DE ESTE CAMBIO el ojo se BORRABA aqui, y no habia forma de
            recuperarlo en partida. Si ves `(ninguno)`, el arreglo no entro.
  [ ] A5.3  Con la fatiga aun a 100, pulsar X para encender.
            ESPERADO: se niega, con los mismos dos mensajes rojos. Sigue apagado.
  [ ] A5.4  `/dojutsudojutsu strain 50`. Pulsar X.
            ESPERADO: ahora SI enciende.
  [ ] A5.5  `/dojutsudojutsu strain 99`. Pulsar X (estando apagado).
            ESPERADO: enciende. El veto es solo el tope, no la fatiga alta.

  [ ] A5.6  LA FORMA ETERNA NO SE PIERDE:
            `/dojutsudojutsu activate mangekyo_itachi`
            `/dojutsudojutsu eternal true`
            `/dojutsudojutsu strain 100`   (fuerza el apagado)
            `/dojutsudojutsu get` -> `eternal=true` SIGUE AHI.
            Este era el segundo efecto del bug: se perdia tambien el EMS.

  [ ] A5.7  RINNE SHARINGAN, EL EXENTO:
            `/dojutsudojutsu activate rinne_sharingan`
            `/dojutsudojutsu strain 100`
            ESPERADO: NO se apaga solo (es el ojo exento) y X sigue pudiendo
            encenderlo/apagarlo con normalidad.

  [ ] A5.8  SIN PENALIZACION CON EL OJO APAGADO: con fatiga >= 95 y el ojo
            APAGADO, no deben aplicarse weakness ni ceguera.
            Con el ojo ENCENDIDO y esa misma fatiga, si.
  [ ] A5.9  Con el ojo apagado, la fatiga sigue BAJANDO sola con el tiempo
            (regen). Comprobar con `get` un par de veces separadas.
